# isb2-kings-layer

Aplikasi web menu restoran berbasis React + Vite + Tailwind CSS (tugas kelompok ISB-2).

## Persyaratan
- Node.js 20 atau lebih baru
- npm 10 atau lebih baru
- Git

## Cara menjalankan
```bash
git clone https://github.com/King-Slayer-ISB-2/isb2-kings-layer.git
cd isb2-kings-layer
npm install
npm run dev
```
Buka http://localhost:5173

## Script
| Perintah | Fungsi |
|---|---|
| `npm run dev` | Development server |
| `npm run build` | Build production ke `dist/` |
| `npm run preview` | Preview hasil build |

## Alur kerja tim
1. Buat branch dari `main`: `git checkout -b fitur/nama-fitur`
2. Commit dan push branch
3. Buka Pull Request ke `main`
